## Classification rules

| Classification | Meaning |
|---|---|
| MATCH | Current BaRe contract is statically reconciled to Reference for the feature. |
| GAP / PARTIAL | Reference contract is known; BaRe feature behavior is not yet fully reconstructed/reconciled. |
| AUTHORIZED DEVIATION | Intentional target difference already authorized by project policy. |
| UNAUTHORIZED DEVIATION | Difference exists without an authorized target rule. |
| UNKNOWN | Reference evidence itself remains unresolved after targeted audit. |
