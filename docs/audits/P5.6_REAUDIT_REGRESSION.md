### 2. Obfuscated Reference-type leakage

**Finding: CONFIRMED / FIXED**

Primary Reference evidence shows defpackage.q63 is a much broader internal file abstraction with directory, stream, descriptor, root/SuFile and file-operation responsibilities. The BaRe 25-line wrapper did not reconstruct that full abstraction; it only supplied the folder-picker path value currently needed by the sole BaRe consumer.

Action:
- Added com.bare.folders.data.FolderSelection.
- Migrated FolderPickerActivity from defpackage.q63 to FolderSelection.
- Removed the obsolete BaRe defpackage/q63.java wrapper.

This is a hygiene/ownership correction, not a claim that the entire Reference q63 filesystem abstraction has been ported. Any future folder-engine requirement must be audited separately from primary evidence before introducing a semantic filesystem abstraction.
